# 下一站巨星 · V1.0 轻量球员生涯

**V1.0 重构版，已获准发布。** [在线游戏](https://lynch715.github.io/next-stop-superstar/)。 从全新球员开始，取消旧存档、旧剧情及其历史兼容。所有金额使用人民币，账目按分保存，概要可用万元显示。

玩法围绕训练与恢复、四种关键球、个人设备、身价和职业合同：

- 关键球上场后，文字战报逐回合滚动，随机穿插投篮、篮板、抢断和过人，动作结束便回到战报，直到终场。小游戏一次点击或左右选择完成；没有摇杆与连续组合操作。小游戏使用透视木地板球场、球衣人物、球路和动作演出；判定先保存，再播放结果。人物按蓄力、发力、腾空和落地分段演出，持球位置跟随关节，出手和接球使用同一手部坐标。
- 八项能力、每周两次安排。私人课程与器材提高训练效率，不制造训练点；免费恢复始终可用。
- 校园培养补助到职业薪资按周到账。购买球鞋、护具、三类器材、恢复设备和个人训练空间，转会后自动保留。
- 身价随能力与正式表现变化。收官后比较薪资、起始角色、平台和年限，试训、签约后注册下一季。
- 校园到 CBA、海外发展与 NBA；沿用当前球队与赛制资料。可以整场模拟或一次推进最多五场。
- 自动保存、导出及导入仅支持本版。比赛中刷新保留已完成动作及同一机会，不重发奖励。

## 本地运行

```sh
python3 -m http.server 8772 --bind 127.0.0.1
```

打开 [本地游戏](http://127.0.0.1:8772/)。仅监听本机；不同端口的进度独立。首次运行创建新球员，不读取旧代存档。

## 文件与验证

- `light-data.js`：人民币价格、能力、设备和特长。
- `light-engine.js`：纯逻辑、统一比赛统计、训练、经济、角色、身价与合同。
- `light-mini.js`：时机操作、画布与单一动画时钟。
- `light-ui.js`、`light.css`：生涯／训练／资产／球队与合同。
- `team-data.js`、`season-format.js`：沿用的球队与赛制资料。

```sh
node test-light.cjs
node test-light-ui.cjs
node test-light-broadcast.cjs
node test-light-mini.cjs
node test-light-balance.cjs 300 100 qa/light-balance-broadcast.json
python3 tools/build_release.py
python3 tools/check_release.py
```

规范见 [轻量球员生涯重构规范](轻量球员生涯重构规范.md)，本地验收见 [验收记录](qa/轻量生涯-本地验收.md)。旧运行脚本与旧测试不进入新的入口或交付包。
